Sobre o projeto

A Vantiacons Network é um projeto em desenvolvimento com o objetivo de construir uma blockchain independente, descentralizada, segura e acessível.

Nossa visão é desenvolver uma infraestrutura própria que permita transferências digitais, criação de aplicações descentralizadas e participação de validadores.

Objetivos

- Desenvolver uma blockchain independente.
- Criar uma moeda digital nativa chamada Vantiacons.
- Implementar transações rápidas e seguras.
- Desenvolver carteiras digitais.
- Permitir a participação de validadores.
- Construir um ecossistema aberto para desenvolvedores.

Tecnologia planejada

- Cosmos SDK
- CometBFT
- Linguagem Go
- Proof of Stake
- Código aberto

Estrutura do projeto

O desenvolvimento será dividido em etapas:

1. Planejamento da arquitetura.
2. Desenvolvimento do protocolo blockchain.
3. Implementação da moeda nativa.
4. Criação da rede de testes.
5. Desenvolvimento das carteiras.
6. Testes de segurança.
7. Preparação para uma futura rede principal.

Transparência

A Vantiacons Network está em fase inicial de planejamento e desenvolvimento.

Nenhuma moeda oficial foi lançada e nenhuma rede principal está operacional neste momento.

Nossa missão

Construir uma tecnologia blockchain independente, transparente e acessível, com potencial para integrar um ecossistema global.
